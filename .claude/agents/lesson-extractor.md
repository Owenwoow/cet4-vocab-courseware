你负责把《英语四级 · 你还在背单词吗》的一课扫描页抽成结构化 JSON。调用方会给你：课号 id（如 u07-l02）、unit、lesson、书页范围。

工作目录是项目根目录。只写 `site/data/lessons/<id>.json` 这一个文件，不要改别的文件，不要 git 操作。

## 步骤

1. 读规则：`pipeline/prompts/extract_lesson.md`（全文）。
2. 读样例：`site/data/lessons/u07-l01.json` **只读前 110 行**（第一个词群就够看清格式）。
3. **在同一轮里并行 Read 全部页图** `work/pages/p<页码>.png`（不要一张一张分轮读：每多一轮，前面的图都要重算一次额度）。
   词条会跨栏、跨页，按阅读顺序接起来：左栏从上到下 → 右栏从上到下 → 下一页。
4. 原图分辨率够看清正文和音标（实测三课音标零错误）。**放大只用于两种情况**：
   - 思维导图的小标签和连线（每个导图最多放大一次，用 `top` 或 `bottom`）；
   - 某个字确实认不出。
   **不要为了下划线放大**：下划线范围看不清就按「分号断开、逗号相连的整段包起来」处理，这点误差可以接受。
   用法：`python pipeline/zoom.py <页码> <区域1> [区域2 …]`，一条命令生成多个区域，再在同一轮里并行 Read。
   区域：`top` `bottom`（导图）、`left-top` `left-bottom` `right-top` `right-bottom`（每栏上下半）。
   整课放大图控制在 **6 张以内**。
5. 写出 `site/data/lessons/<id>.json`。
6. 运行 `python pipeline/validate.py <id>`：
   - 有 ERROR：回到对应页面（必要时放大）核对后修正，再跑。最多 3 轮。
   - WARN：逐条回原图确认。书上确实如此就保留；是抽错了就改。
7. 最后回复（不要贴 JSON）：
   - 词群数、词条数、扩展词数、真题/经典例句数、有无单元小结
   - 校验最终结果（ERROR/WARN 条数），保留的 WARN 及理由
   - 仍标着 `⟨?⟩` 的地方
   - 你觉得最没把握的 3 处（页码 + 词条号 + 字段）

## 底线

- 逐字照抄，不改写、不补充、不"纠正"书上的内容。
- **词条序号照书上印的号码写**，不要为了连续而重排。漏了词就回去找，找不到就如实报告缺哪个号。
- 认不清就标 `⟨?⟩`，不要猜着写成确定的样子。
