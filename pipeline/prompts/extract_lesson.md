# 任务：把一课书页扫描图抽取成 Lesson JSON

适用模型：任何能看图的模型（Claude Sonnet / Qwen-VL / GLM-4V / Gemini Flash 等）。
输入：一个 Lesson 的全部页图（按页码顺序），以及 unit、lesson、起止页码。
输出：**只输出一个 JSON 对象**，不要任何解释文字，不要代码围栏。

## 最高原则

**逐字照抄书上内容，不改写、不补充、不纠错。** 书上没有的字段填 `null` 或 `[]`，不要自己编。
认不清的字，照最可能的写法写，并在该字段末尾加 `⟨?⟩`，校验脚本会把它挑出来给人看。

## 忽略这些

页眉（"学丞·晓艳英语…""PART 01 词以群记·抓核心"）、页脚励志语和页码、右侧"Unit 7 Lesson 1"竖标签、左下角二维码和广告水印、"Lesson 1"大标题。

## 结构

```
{
  "id": "u07-l01", "part": 1, "unit": 7, "lesson": 1, "pages": [起页, 止页],
  "groups": [ 词群, ... ]
}
```

**词群**（书上红底"词以群记 N"标题开始一个新词群，N 在整个 Unit 内连续编号）：

```
{ "no": N, "title": "“边缘”相关", "pages": [起页, 止页], "map": 导图, "entries": [词条, ...] }
```

- `title`：标题照抄，保留中文引号 “ ”。
- `pages`：这个词群的导图和词条跨越的书页。

**导图 map**：一棵树。根是中间的云朵（文字同标题），往外每条连线一个子节点。

```
{ "w": "“边缘”相关", "children": [
  { "w": "margin", "children": [ { "w": "marginal", "rel": "扩" } ] }
]}
```

- `rel`：连线上的小字标签，照抄：扩 / 近义 / 相关 / 形近 / 反义 / 同根 / 音近 / 加s …；连线上没有标签就不写 `rel`。
- 一条线上串着几个词（A — B — C），就是 A 的子节点 B、B 的子节点 C。
- 一个标签引出一个括号分叉到多个词时，每个词都是同一父节点的子节点，都带这个 `rel`。

**词条**（红底白字序号 01、02…，**每个 Lesson 从 01 重新编号**，词条可能跨栏、跨页，要接起来）：

```
{
  "no": 1, "word": "margin", "freq": 3, "page": 191,
  "prons": [ { "ipa": "/ˈmɑːdʒɪn/", "senses": [ { "pos": "n.", "mean": "[[边缘]]；[[利润]]；极限；白边，页边空白处" } ] } ],
  "tip": { "type": "联想", "text": "mar（联想 Mars）+ gin（音似“进”）→ 探测器要从“边缘”进入火星。" },
  "ex": { "type": "例", "en": "...", "zh": "...", "key": ["margins"] },
  "ext": [ { "word": "marginal", "ipa": "/ˈmɑːdʒɪnl/", "senses": [ { "pos": "adj.", "mean": "小的，微不足道的；不重要的" } ] } ]
}
```

- `freq`：词条标题行右侧火苗个数，1~3。
- `page`：词条标题所在书页。
- `prons`：通常一个。像 import 那样**不同词性不同音标**分两行写的，拆成两个 pron。
- `ipa`：用标准 IPA 字符：重音 `ˈ`（不是 `'`）、次重音 `ˌ`、长音 `ː`（不是 `:`）、`ɡ`、`ɪ`、`ʊ`、`ə`、`ɒ`、`ɔ`、`ʌ`、`æ`、`ʃ`、`ʒ`、`θ`、`ð`、`ŋ`。
- `pos`：`n.` `v.` `adj.` `adv.` `prep.` `conj.` `pron.` 等；书上写 "n. & v." 就照写。
- `mean`：**书上加了下划线的释义用 `[[ ]]` 包起来**（下划线=常考义）。标点用中文全角 ；，（）。
  一条下划线连着跨过逗号（如「企业，商业」下面是一整条线）就整段包成一个 `[[企业，商业]]`；分号两边的线是分开的，就分开包。
- `tip`：黄框里的记忆法。`type` 取绿/橙/蓝小标签的字：联想 / 构词 / 谐音 / 对照。没有黄框填 `null`。
  文字里的箭头统一写成 ` → `。
- `ex`：
  - `type`：粉色「真」图标 = `"真"`，并填 `"year": 年份`（句末括号里的年份，不要写进 zh）；蓝色「例」图标 = `"例"`。
  - `en`：英文例句照抄；`zh`：中文译文照抄。
  - `en` 里的撇号、引号**一律用直的** `'` `"`（书上印的是弯的 ’ “ 也要改成直的），否则网页会把 wasn't 拆成两个词。
  - `key`：例句里**用彩色标出的词**，按原样（含词形变化）逐段列出，如 `["is bound to"]`、`["acquaint", "with"]`。
  - 本页没有例句、下一页才有的，要接上；整条确实没有例句填 `null`。
- `ext`：带橙色「扩」图标的扩展词，接在它所属词条后面。`specialise/-ize` 这种写成 `"word": "specialise", "alt": "-ize"`；
  `vigo(u)r` 这种括号拼法写成 `"word": "vigour", "alt": "vigor"`（word 用括号字母保留的完整形式）。词条本身同理。

## 单元小结（只有每个 Unit 的最后一课才有）

Unit 最后一页有个带卡通人物的框「本单元已学习：N 个词群、N 个单词、N 个扩展词、N 个真题例句、N 个经典例句」。
看到它就在顶层加（没看到就不要这个字段）：

```
"unit_summary": { "groups": 13, "words": 194, "ext": 113, "zhen": 84, "li": 110 }
```

## 只抽本课

给的页码范围就是本课。页内出现下一课的「Lesson N」大标题时，它后面的内容不属于本课，不要抽。

3. 每个 `key` 都能在对应 `en` 里原样找到。
4. 音标里没有 `'` 和 `:`。
