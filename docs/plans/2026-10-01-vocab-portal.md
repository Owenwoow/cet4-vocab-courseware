### 滚动复习规则（`srs.js`）

一条好记的话：**工作日早上复习「昨天的 + 上周今天的」，周末复习「本周的 + 上上周的」**。实现是按词算的，所以每天学多少、哪天没学都不影响。

- 一天从凌晨 4 点开始算
- 只排主词条（扩展词不进）；「已会」的词不出现
- 记录某个词群为某天学的 → 其中每个主词条建一张卡：学习日 a，已过站数 s=0，到期 a+1
- 在到期日当天或之后复习：
  - 记得 → s+1，下一站：
    - s=1（次日已过）→ a+2 之后第一个周六或周日（本周末）
    - s=2 → a+7（上周今天）
    - s=3 → a+14 之后第一个周日（上上周，落在周日）
    - s≥4 → 今天 +21（考前每 3 周至少见一次）
    - 任何一站都不早于明天
  - 模糊 → 站数不变，2 天后再来
  - 忘了 → 遗忘次数 +1，从今天重新开始（a=今天，s=0，明天到期），进难词本
- 还没到期就复习（途中看、睡前巩固、周总结里多刷）：记得 / 模糊不改计划；忘了照样重来
- 每天复习有上限（默认 120）：到期的按「拖得最久 → 火苗多」排序，超出的留到之后几天
- 请假顺延 N 天：所有卡片的学习日和到期日整体后移 N 天
- 难词本：最近一次评「忘了 / 模糊」，或遗忘 ≥ 2 次
- 数据走 `sync.js`：`learn:<课id>:g<词群号>` = 日期（取消记 0）；`srs:<词>` = {a, s, d, l, r, n}（取消记 0）；`log:<日期>` = 当天评分计数
