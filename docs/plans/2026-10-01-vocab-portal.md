### 滚动复习规则（`srs.js`）

一条好记的话：**工作日早上复习「昨天的 + 上周今天的」，周末复习「本周的 + 上上周的」**。实现是按词算的，所以每天学多少、哪天没学都不影响。

- 一天从凌晨 4 点开始算
- 只排主词条（扩展词不进）；「已会」的词不出现
- 记录某个词群为某天学的 → 其中每个主词条建一张卡：学习日 a，已过站数 s=0，到期 a+1
- 在到期日当天或之后复习：
  - 记得 → s+1，下一站：
    - s=1（次日已过）→ a+2 之后第一个周六或周日（本周末）
    - s=2 → a+7（上周今天）
    - s=3 → a+14 之后第一个周日（上上周，落在周日）
    - s≥4 → 今天 +21（考前每 3 周至少见一次）
    - 任何一站都不早于明天
  - 模糊 → 站数不变，2 天后再来
  - 忘了 → 遗忘次数 +1，从今天重新开始（a=今天，s=0，明天到期），进难词本
- 还没到期就复习（途中看、睡前巩固、周总结里多刷）：记得 / 模糊不改计划；忘了照样重来
- 每天复习有上限（默认 120）：到期的按「拖得最久 → 火苗多」排序，超出的留到之后几天
- 请假顺延 N 天：所有卡片的学习日和到期日整体后移 N 天
- 难词本：最近一次评「忘了 / 模糊」，或遗忘 ≥ 2 次
- 数据走 `sync.js`：`learn:<课id>:g<词群号>` = 日期（取消记 0）；`srs:<词>` = {a, s, d, l, r, n}（取消记 0）；`log:<日期>` = 当天评分计数

## 决定

- **复习规则用固定站点，不用 FSRS**：只剩 10 周，FSRS 按词自适应的优势要几个月才显现；用户要按周可预期的节奏。站点：次日 → 本周末 → 上周今天 → 上上周（周日）→ 每 21 天。规则在 `site/srs.js`，有单元测试
- **模糊**：站数不变、2 天后再来（比「照走下一站再加一次」简单，效果接近）
- **提前复习不推进计划**：途中看、睡前巩固、周总结多刷时，记得 / 模糊不改到期日，只有忘了会重来；否则睡前一刷就把「次日早上」那一站跳过了
- **词群日期和卡片学习日分开存**：忘了重来会改卡片的学习日，但「今天学的 / 本周学的」按词群日期筛，不会把重来的旧词算进今天
- **每次巩固只有第一次评分算数**：忘了的词当场循环到记住，循环里的再评分不再改计划
- **扩展词不进复习**；「已会」的词不出现在任何复习范围里
- **按书上的范围抽查**（某 Unit / Lesson）：没记为学过的词也能抽，但不排复习、不记分
- **每天复习上限默认 120**：到期的按拖得最久 → 火苗多 → 课本顺序排，超出的自然留到之后几天；积压超过上限或 3 天没学时首页提示，可整体顺延（请假）
- **一天从凌晨 4 点开始算**
- **Web Awesome 只引主题变量 + 组件加载器**：不引 `native.css`、不用 `wa-page`，课文页外观不变；颜色变量映射到本站的 `--accent` 等，深浅色用 `wa-dark` 类跟随本站主题设置
- **别的设备同步来新阅读位置时**，只有正在看课文才跟着跳；首页、巩固中不打断
- **侧边栏只当书的目录**（用户反馈）：首页、巩固、周总结的入口首页上都有，侧边栏不重复
- **记录方式改为目录式「学习记录」页**（用户反馈：课文页里词群之间隔着很多词卡，来回翻太麻烦）：`#/log` 按书的目录排 Unit → Lesson → 词群，勾上再保存；首页「学新」和课文页顶部都只放一个「📝 学习记录」入口。试过首页列出接下来 5 个词群点选，用户不要，已删。每课是一张连成一体的列表，勾上的行左边竖线 + 浅底，连续勾的连成一段；课文页只保留「✓ 学过」标记
