# 统一学习状态与模式调度

用户授权本地开发；本次不提交、不推送、不部署。原始备份只读，保留课件、词卡风格及正式回忆间隔公式。

- 单一学习状态读取既有已学词群、卡片、已会及快背/正式练习历史。全书已接触共用；快背覆盖不等于精背训练完成，已有卡不再直接作为跳过精背的条件。
- 原有明确已学记录计入覆盖；快速已接触的词保留待精学资格，主任务可自动安排首次正式回忆。旧词校准进度、等级、排期和历史时间保持。
- 每日计划使用一个时间预算：旧设置按真实修改时间承接到共享设置；当天预算固定，切换后只在剩余预计时间内安排，不用识别题张数冒充精背完成。
- 旧词单和断点兼容；旧快背词单升级保留实际已做结果。计划及预算跨端取确定的首份，显式备份覆盖保留恢复批次。
- 已有数据自动升级，无需手动导入。真实样本仅在内存中验证；浏览器验收只用演示数据，不导入真实备份、不连接 Gist。

实施完成：

- `learningState` 为纯读取状态层，集中承接已学词群、已会、书内生词加入记录与正式/识别事件。生词卡的 `p` 是音标，不能当成精学完成日期；书内覆盖按单词去重。
- `set:studyMinutes` 统一设置，旧的两种时间设置取实际修改时间较新的值，并沿用其原同步时间；`studyday:<日期>` 冻结当日预算。主任务、补测、快背看卡与检查按事件成本共用预算，退出或切换不退款、不虚构首答。
- 快背看卡的成本单独保存到 `quick:seen:`，只占预算，不凭空算检查完成。识别完成成本扣除已记录的看卡部分，避免重复计时。
- 快速来源卡可进入“接触词精学”的正式任务；新词闯关和当日断点也不再仅凭已有卡或词群标记跳过。完成整群训练写入精学日期，保留最早接触记录及原有回忆证据。
- 旧快背计划升级为 v2，既有逐词结果保留，首页进度与课程圆环统一显示全书已接触。两模式的训练完成、首答与掌握仍分别按真实记录计算。
- 同一今日学习路由切换模式会重新衔接正确流程；预算不足的训练明确延期，不记成已完成。完成日预测先扣除当天实际可安排量，再计算后续日期。
