- 状态：已完成
- 日期：2026-10-14
- 需求原话：
  1. 干扰项与正确答案不能有共同义项（如 elect 的"选择"与 select 的"选择"重复则换掉）

  5. 完成后提交并推送

## 决定

- 义项比较用「完全相同的义项词」：释义按 ，；、 拆开，去掉词性和括号里的补充（「（使）适应」→「适应」）。按字重叠比较误伤太多，所以没用；近义但字不同的仍可能同时出现（记入待人工验收）
- 词性辨析 = 形近 + 有共同义项 + 词性完全不重叠；不形近但有共同义项的（injury / harm）照样不能用
- 混淆（选中形近 / 同词群 / 词性辨析的干扰项）：复习评分记 m（模糊），不按 f 重来；本轮仍要再答对一次；学新词时这一关重来，但不计入错误次数（不会因混淆进难词本）
- 词性辨析的干扰项和答案词性必然不同，原来的「同词性 +2」会让它总被同词群挤掉（走查 160 次一次都没出），所以计分时按同词性算
- 对比复习存在卡片字段 `cf`（最多 3 个，最近的在前），`SRS.rate`、`chop` 都用展开保留，不需要改 `sync.js`；本轮内另用 `D.cf` 记着，没有复习卡的词（按书上范围抽查）也能在本轮内对比
- 本轮验证：validate 通过，单元测试 34/34；本地 8775 走查 opt→collect 近义混淆、exceed→excess 词性混淆、再来一次时 excess 固定在选项里
