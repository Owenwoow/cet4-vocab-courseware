# 开放收录 + 首页级 SEO + README

状态：已完成

【目标】网站能被搜索引擎收录和搜到，GitHub 仓库有像样的 README、简介和网站链接。

【要做】
1. 去掉 `noindex`，`robots.txt` 放开并加 `sitemap.xml`
2. `index.html` 头部：标题、description、keywords、canonical、OG / Twitter 分享卡片（`site/og.jpg`）、JSON-LD（WebApplication）、`<noscript>` 静态简介（不跑 JS 的爬虫如百度也能读到）
3. 首页标题不再被 JS 改成「首页 · 四级词汇」，保持 `index.html` 里的完整标题（`study.js` 的 `HOME_TITLE`）
4. 顶栏加 GitHub 图标（≤600px 隐藏，免得挤掉面包屑），课文页和首页页脚加「GitHub 项目」链接
5. README：功能介绍 + 浏览器截图（`docs/images/`，演示数据是脚本模拟的两周学习记录）；仓库简介、topics、网站地址

【不做】
- 每课生成预渲染静态页：收录效果更好，但书上内容会被全文收录，版权风险最高（用户选了首页级）

【已定的取舍】
- 推翻 2026-09-30 计划里「只给自己用：noindex + robots 禁止收录」的决定；已提醒用户内容逐字取自原书，收录后更容易被投诉（DMCA 可能下架仓库和 Pages），用户确认放开
- 课文路由是 `#/…` 哈希地址，搜索引擎只当一个页面，sitemap 里只有首页

【验收】本地预览首页源码里没有 noindex；robots.txt / sitemap.xml 可访问；顶栏和页脚链接指向 GitHub；首页标题是完整标题；测试全绿
