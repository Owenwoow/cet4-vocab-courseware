## 决定

- **生词单独存 `vocab:<原形>`，复习规则复用 `srs.js`**：`markGroups` 遇到已有 `srs:` 卡的词会跳过，生词要是也用 `srs:`，以后学到那个词群时书上的卡就建不出来。复习站点、四档评分、难词本、请假顺延都和书上的词一样；生词火苗记 0，同一天到期时排在书上的词后面，课件顺序里排在所有书上的词之后
- **加入当天算学习日**：「今天学的 / 途中看 / 睡前巩固 / 本周」按生词的加入日期算，不按词群日期；首页「学新」显示「+ 生词 N 个」，周总结的新学词里含生词并列出当天加的
- **原形**：释义里有「（X 的复数 / 过去式 / 分词 / 三单 / 比较级 / 所有格…）」就取 X；缩写、否定、多词标注保留原样；没有标注时按词形变化去书的目录里找；短语原样。变形标注和「found」的音标在存原形时去掉
- **生词其实是书中词条**：卡片和列表显示书上的完整内容（释义、记忆法、词根、例句），另加绿色「遇见」例句；把那个词群记为学过时生词毕业（记 0）。书上已在复习的词，弹窗按钮改为「记一次忘了」（明天再来、进难词本，标过已会的同时取消已会）。扩展词的生词不毕业（扩展词本来不进书上的复习）
- **显示和存取用两个标志**：`vocab` = 卡存在 `vocab:` 键；`nb` = 按生词显示。书上范围（#/list/u05-l04、按单元抽查）里的生词仍按词群显示，只多一个「生词」小标签（代码审查发现的问题）
- **速览改成「导图 / 词表」两个标签**：原计划导图和词表上下排，实测导图高 180–670px，和十几行词表一屏放不下。记住上次看的标签；导图里点词在底部显示释义，不用切走导图
- **速览浮层宽 520px**：440px 时大部分树形导图放不下，520px 能放下一半左右；放不下的自动换成手机版紧凑导图（导图显示出来才量宽度）
- **巩固范围多了「生词本」，改成每行 3 个**（9 个）；首页入口 4 个，手机上每行 2 个
- **扩展词不单独加生词本，改为巩固卡背面附带列出**（用户反馈：扩展词本来就跟着主词条背，只是附带记忆）：去掉扩展词行的「＋」；巩固翻开主词时在例句下面列出它的扩展词（可点读），不单独打分、不单独排复习。途中看的列表仍只列主词。例句里点到别的课的扩展词照样能加生词本
