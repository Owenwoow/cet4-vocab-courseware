# B 站外链播放器净化脚本

- 状态：已完成本地实现与验证，未推送；扩展安装验收待用户确认。
- 目标：安装油猴脚本后，课件小窗暂停时只留下视频画面和正常播放控件。
- 分档：小改动；顺序实现、浏览器实测、全量检查、本地提交，不推送。
- 文件：`site/tools/bilibili-clean-player.user.js`；本计划；`docs/待人工验收.md`。

## 已决定

- 2026-10-19 的“去不掉”结论仅适用于课件本身。课件受跨域限制，油猴扩展可将脚本注入 `player.bilibili.com/player.html`，直接添加样式。
- 只匹配 B 站外链播放器，保留 iframe 注入，不匹配普通 B 站视频页，也不需要读取学习记录、账号或 Cookie。
- 用精确选择器隐藏标题作者与互动浮层、暂停推荐、高清引流、弹幕发送引流；播放时也隐藏这些提示。
- 保留视频、字幕、错误和缓冲提示、弹幕开关、进度条、播放按钮、时间、画质、倍速、音量和全屏。
- 不改课件嵌入方式，不改点击画面暂停的已有逻辑；继续播放仍可使用左下角播放按钮。
- 脚本由油猴独立运行，不加入课件脚本加载列表，因此无需添加部署版本号替换。

## 安装和验收

1. 浏览器安装并启用篡改猴（Tampermonkey）后，打开本地 `http://localhost:8765/tools/bilibili-clean-player.user.js`，在扩展安装页安装。若浏览器只显示源码，在扩展中“添加新脚本”，用此文件全部内容替换默认模板并保存。
2. 扩展需获准访问 `player.bilibili.com`，并允许脚本在子框架运行。若扩展提示启用“允许用户脚本”或开发者模式，按其提示操作。
3. 刷新课件网页，重新打开视频小窗并暂停：推荐卡片、标题作者、互动按钮和高清引流不出现；画面和底部控件正常。
4. 用播放按钮继续，拖动进度、调整倍速和音量、切换全屏，再切另一个词的视频重复暂停。
5. 如需恢复原播放器，在扩展中停用本脚本并重新打开小窗。
