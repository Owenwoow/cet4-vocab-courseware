# 智能背词：学习循环 + 熟练度 + 多题型

- 状态：方案已定，待开工
- 日期：2026-10-12
- 需求原话：
  1. 想实现更强更智能的单词背诵功能（动态整理排布背诵顺序，记录单词熟练度等）；保持纯前端
  2. 改进后续的复习方案：复习过 3 次后不按单词顺序、随机出；熟练度要有好的体现，熟练度高的单词降低显示；参考不背单词等成熟软件，增加背诵形式（现在只有遮住单词猜意思）；考虑人脑记忆规律
  3. 背诵时要用四选一；一次背诵循环学习，直到所有单词都会了
  4. （确认）学新词的循环以按钮进入；第一次四级考试 2026-12-12；熟练度淡化只做首页和词表，课文页不变
- 结论：纯前端即可（单用户、约两千词，计算在浏览器里毫秒级；跨设备照旧走 `sync.js` 的 Gist）

## 设计依据（记忆规律）

- 主动回忆优于再认：题型从「认得出」→「想得起」→「拼得出」逐级加难
- 间隔递增：越熟隔得越久，已牢记的词少出
- 穿插（乱序）：前几次按词群出，借书上的联想；复习满 3 次后打乱，检验脱离上下文能否认出
- 反应时间是信号：答对但慢 = 模糊
- 当场重学：错的词本轮内隔几张再出，直到答对
- 一次背的量有限：同时在背的新词最多 8 个；复习每轮最多 25 个

参考：Anki/FSRS（按熟练度拉开间隔）、不背单词（题型递进、太简单一键移出）、百词斩（斩、拼写）、墨墨（四档评分）、扇贝（本轮内重现）。

## 一、学习循环（学新词、复习通用）

- **结束条件**：本轮每个词都过关才结束
- **学新词过关**：两关都答对——① 看词选义（四选一）② 听音选义（只放读音，不显示单词，四选一）。任何一次答错，这个词两关重来
- **复习过关**：答对一次
- **答错**：立刻显示完整词卡（释义、例句、词根补充、读音），隔 3～5 张后再出
- **「不认识」按钮**：算答错，防止蒙对
- **防死磕**：同一词本轮错 3 次 → 进难词本，之后再对一次即放行
- **小组滚动**：学新词时同时在背最多 8 个，过关一个补一个
- **成绩只看第一次作答**：循环只保证离开时都会了；排计划、算熟练度用本轮第一次的结果
- **断点续背**：未完成的本轮经 `sync.js` 存一份，关掉页面能接着背
- **入口**：首页两个按钮 `[今日复习 N]` `[学新词 N]`；习惯上先复习再学新。课文页标记「学过」流程不变，不自动弹出

## 二、作答记录

每个词每轮只记第一次作答：

| 情况 | 记为 |
|---|---|
| 选择题答对，≤5 秒 | `g` 记得 |
| 选择题答对，>5 秒 | `m` 模糊 |
| 拼写全对 | `g` |
| 拼写错一个字母（编辑距离 1） | `m` |
| 答错 / 按「不认识」 | `f` 忘了 |
| 快速抽查（5 级）自评 | 按所选 |

## 三、数据（`srs:<词>` 新增字段，旧字段不动）

| 字段 | 含义 | 例 |
|---|---|---|
| `h` | 最近 6 次第一遍结果 | `"ggmgg"` |
| `q` | 第一遍答对过的最难题型等级 0～3 | `2` |
| `z` | 手动「斩」过 | `1` |

题型等级：0 看词选义；1 听音选义；2 例句挖空选词 / 看中文选英文；3 拼写。旧卡缺字段时按 `h=""`、`q=0`、`z=0` 处理。生词本 `vocab:<原形>` 的复习卡同样加这三个字段。

学新词循环中错 ≥2 次的词：`h` 先记一个 `f`（第二天早上显示红色、优先出），复习日期不变（仍是次日）。

## 四、熟练度 `level(card)`

连对 = `h` 末尾连续 `g` 的个数。从上往下，命中即止：

```
z=1                                   → 5 牢记
n=0（还没复习过）                     → 0 新学
h 末位是 f，或 l≥2 且 连对<2          → 1 生疏
s≥4 且 连对≥4 且 q≥3                  → 5 牢记
s≥4 且 连对≥3 且 q≥2                  → 4 掌握
s≥3 且 连对≥2                         → 3 熟悉
其他                                  → 2 认识
```

- 只会四选一最多到 3 级；4 级要过例句挖空 / 看中文选英文，5 级要拼对过
- 一次 `f` 降到 1 级；`m` 不降级但打断连对

## 五、出题 `pickType(card)`

题型 = min（熟练度对应题型, q + 1）——每次最多升一级。

| 熟练度 | 题型 |
|---|---|
| 0～1 | 看词选义 |
| 2 | 看词选义 / 听音选义轮换 |
| 3 | 例句挖空选词、看中文选英文 |
| 4 | 拼写（释义 + 读音，给首字母） |
| 5 | 快速抽查：只显示单词，1 秒内自评 |

干扰项：优先同课、同词性的其他词释义，再从形近词里挑（如 adapt / adopt）。

## 六、复习间隔

- **站数 s=0～3：完全不变**（次日 → 本周末 → 一周后 → 两周后的周日）
- **s≥4**：原来固定 +21 天，改为按熟练度：1～2 级 7 天、3 级 14 天、4 级 21 天、5 级 30 天
- **模糊**：s≤3 照旧 2 天后；s≥4 取上面间隔的一半，至少 2 天
- **忘了**：照旧从今天重新开始
- **提前复习**（未到期）：照旧不改计划，忘了照样重来
- **考前封顶**：考试日 `EXAM = "2026-12-12"`（常量，换六级只改这里）。算出的到期日晚于 12-09 时，改到 12-05～12-09 之间，按单词哈希分到各天使量均匀；12-10、12-11 只复习 1 级（生疏）的词；考后不再封顶

## 七、出题顺序

- 复习不到 3 次（`n<3`）：课件顺序，同词群放一起
- `n≥3`：乱序；同词群、同课不相邻；形近词有意放在一起
- 当天到期列表：拖得最久的先 → 熟练度低的先 → 其余乱序；每轮最多 25 个，多了分轮

## 八、熟练度显示（只改首页和词表，课文页不变）

- 首页：熟练度分布条（生疏 / 认识 / 熟悉 / 掌握 / 牢记 各多少个），点某一段进入对应词表
- 词表：每个词前加颜色点（○ 🔴 🟠 🟡 🟢 ⚪）；4～5 级变淡，可折叠
- 巩固卡：加「斩」按钮（设 `z=1`，30 天后抽查；抽查答错照常降级并清掉 `z`）
