# 学习新词页面加「词群速览」（导图 + 词表）

- 状态：已完成（2026-10-19，随 2026-10-19-batch.md 一起执行）
- 日期：2026-10-19
- 来源：本会话 /dev-ask（一批 4 条里的 C；A、B 见 2026-10-19-video-split.md，D 设置另有计划文件）
- 需求原话：新学单词，有 book 的思维导图显示和快速查看前后单词的功能，在一个页面上快速翻看。追问后：「就是 book 中查看当前词群的功能」（课文页右下角「群」/ M 键的词群速览）。另：视频只对电脑端更新，剩下的内容所有端都要更新

## 交接单

```text
/dev-task
【目标】学习新词时，页面上同时有这一群的书上导图和词表（和课文页「词群速览」一样），随时前后看本群的词；学习节奏不变；电脑和手机都做
【要做】
1. 把课文页「词群速览」的导图和词表画法抽成能复用的函数：现在 mapHTML / mapCompact / nodeChip / peekRow 依赖课文页的全局 WORDMAP 和 L，改成接收「这一群的词条查表」参数，课文页照旧传 WORDMAP，行为不变（site/app.js）
2. 学习新词（study.js 范围 learn，D.learn 为真）页面加速览：
   - 宽屏（≥1180px，和现有的宽屏断点一致）：左右两栏，左栏放速览，右栏是现在的词卡 / 题目。左栏上面是导图（树形放不下自动换紧凑版 .mmc），下面是词表；左栏自己滚动，不跟右边一起滚
   - 窄屏（<1180px，含手机）：速览放在词卡上方，默认收起成一行（「词群 N 标题 · 共 M 词 · 正在学 第 k 个」），点开展开导图 + 词表，再点收起；展开 / 收起记住（走 Sync，和 peekTab 一样用 store）
   - 词表每行：序号 · 单词 · 音标 · 释义；点一行展开记忆法、扩展词并读一遍（同课文页速览）；当前正在学 / 正在考的词高亮；已过关的打 ✓；已会的照旧标「已会」。去掉课文页那个「跳到这张卡」按钮
   - 点导图里的词：下面显示它所在词条的释义（扩展词标出那一行）并读一遍（同课文页 peekFoot）
   - 按 M 收起 / 展开速览（和课文页一致）
3. 答题时不泄露答案：题目还没答（q.state === "ask"，或翻卡还没翻开）时，速览里所有释义、记忆法、扩展词释义都遮住（复用背诵模式 .mask 的模糊效果），点词表行、点导图里的词只读音不展开；答完 / 翻开后恢复。「先看一遍」的词卡和回看时不遮
4. 只改学习新词；其他巩固范围（今天到期、睡前、难词本……）不加速览
5. 文档：study.js 文件头巩固模式那段、docs/plans/2026-10-16-learn-new.md 末尾补一句指向本文件
【不做】
- 改学习节奏（仍是「先看词卡 → 隔 3～5 张考看词选义、听音选义两关」，用户选了节奏不变）
- 先整群翻看再考的模式
- 其他巩固范围、复习卡上加导图
- 手机上左右滑动翻词
【已定的取舍】
- 速览照搬课文页「群」面板：用户原话「就是 book 中查看当前词群的功能」
- 电脑上左导图、右词卡：导图一直在眼前，用户选的
- 节奏不变：速览只是随时可看的参考，不影响出题队列和过关规则
- 电脑、手机都做：用户补充「视频只对电脑端，剩下的所有端都要更新」
【默认假设】
- 宽 / 窄分界用 1180px（站里已有这个断点）；窄屏用「词卡上方可收起的一栏」而不是课文页那种底部浮层，因为学习页本来就要一直对照着看
- 答题时遮住释义（第 3 条）：测验时导图怎么处理用户没有偏好；词表里有中文释义，不遮会直接泄露答案
- 速览里的词条数据用学习新词已经取到的这一课数据（getLesson 的缓存），不另外请求
- 学习新词的「先看一遍」词卡仍自动读音；在速览里点词读音时，先停掉正在读的
【验收】
- node --test "tests/*.test.js" 全过、python pipeline/validate.py 0 错误
- 本地 8775 走查（电脑 ≥1180 宽）：进学习新词，左栏有本群导图和词表，当前词高亮；点词表行展开并读音、点导图词底部出释义；答题时左栏释义模糊、点了不展开，答完恢复；过关的词打 ✓；按 M 收起展开
- 375 宽走查：词卡上方一行收起的速览，点开有紧凑导图和词表，同样的遮挡规则；收起状态刷新后保持
- 课文页右下角「群」速览行为不变（回归）
- 中途刷新，接着学，速览状态正确
【线索】
- 课文页速览：site/app.js「词群速览」一节（openPeek、peekRow、setPeekTab、peekFoot）、「思维导图」一节（mapHTML、mapCompact、nodeChip）；样式 site/style.css 的 .peek、.pk*、.mm、.mmc，背诵模式遮挡 .mask .peek .pk:not(.open) .pkm
- 学习新词：site/study.js 巩固模式一节（startDrill、learnItems、showCard 里 q.kind === "study" 的分支、D.st 每个词的 seen / stage / err、D.done）
- 宽屏断点：site/style.css 的 @media (min-width:1180px)
```

## 结果（2026-10-19）

- 导图 / 词表画法（mapHTML、mapCompact、nodeChip、peekRow）加了 map / go 参数，课文页照旧传 WORDMAP；学习新词页按「当前词所在的群」画速览（study.js lpBuild / lpPaint / put），换群只重画速览
- 展开 / 收起记在 learnPeek，宽屏、窄屏各记各的（{w, n}）：总控走查时发现共用一个值时，电脑上展开会让手机也默认展开、占掉大半屏，已改
- 听音选义时词表里当前词的拼写不遮，只遮释义、记忆法、扩展词释义
- 已验证（8775）：1400 宽左右两栏、当前词高亮、答题时遮住且点了不展开、答完恢复、过关打 ✓、M 键收起展开；375 宽收起成一行、点开展开、状态刷新后保持；课文页「群」速览回归正常
- 坑：给 mapHTML 加 map 参数后，递归里必须显式传 map，否则会悄悄退回 WORDMAP

## 返工（2026-10-19，上线后用户验收不合格）

- 用户原话：「怎么把所有东西都显示在一个页面上了呢，我不是进入了一个新页面了吗。词群显示默认收起，点击按钮显示书本页面是如何设计快速回看整个词群的单词的」
- 改成：学习新词页面恢复单栏，速览默认不显示；右下角「群」按钮或按 M，打开和课文页完全一样的速览浮层（电脑右侧抽屉、手机底部弹层，导图 / 词表两个标签，标签选择和课文页共用 peekTab）
- 浮层显示当前词所在的那一群，当前词高亮「▸ 正在学 / 正在考」，过关打 ✓，没有「跳到这张卡」；题目没答完时释义模糊、点词只读音；浮层开着时不答题（按键不生效，Esc 只关浮层）
- 去掉了左栏、词卡上方那一栏和 learnPeek 记录（不再需要记住展开状态）
- 实现：app.js openPeek(src) 接收别的页面传来的词群数据；study.js lpSrc 组装这份数据
- 已验证（8775）：1400 宽和 375 宽默认不显示、点「群」打开、M 开关、Esc 关闭且不影响答题、答题时遮挡和点了不展开、答完恢复、✓；课文页「群」速览回归正常
