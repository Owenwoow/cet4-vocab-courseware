# 学习新词、复习的规则做成设置项

- 状态：已决定，未执行
- 日期：2026-10-19
- 来源：本会话 /dev-ask（一批 4 条里的 D；A、B 见 2026-10-19-video-split.md，C 见 2026-10-19-learn-peek.md）
- 需求原话：设置方面优化，主要针对新学单词和复习单词设计，某些设置不一定要定死，将一些功能添加到设置中，可自定义选择触发。补充：视频只对电脑端更新，剩下的内容所有端都要更新
- 用户对 12 个候选项回复「按推荐」：加第 1、2、3、4、6、7、8、9、10、11 条，不加第 5、12 条

## 交接单

```text
/dev-task
【目标】把学习新词和复习里写死的几条规则放进设置页，默认值等于现在的行为；电脑、手机都生效（设置走 Sync 云同步）
【要做】
1. 新设置项（site/app.js 的 DEFAULTS，键 set:<名字>，默认值 = 现在的行为）：
   ① learnStages 每个新词过几关：1 关（只看词选义）/ 2 关（看词选义 → 听音选义，默认）/ 3 关（再加拼写）。过关条件改成 stage ≥ learnStages（错满 3 次后再答对一次也算，照旧）；含空格的词条第 3 关用看义选词代替拼写
   ② learnSize 一次学多少：1 群（默认）/ 2 群 / 至少 15 词（不够 15 就按书顺序接下一群，最后一群整群带上不拆）。learnItems、进度里的 g（改成能存多群）、结束页和首页「下一群」的文字跟着改
   ③ autoSay 改名「自动读单词」，学习新词的「先看一遍」词卡也按它（现在总是读）；默认开
   ④ autoEx 词卡自动读例句：默认关；打开后学习新词「先看一遍」词卡读完单词接着读例句（只在这张词卡上）
   ⑤ autoNext 答对后自动下一题：默认关；打开后选择题和拼写题判「记得」时停 1.5 秒自动进下一题，期间按任意键或点页面就停在这张卡；模糊、答错、混淆仍停住等「继续」。学习新词的两关也算
   ⑥ slowMode 想得久算模糊：宽松（时限 ×1.5）/ 标准（默认，现在的 8/8/10/15 秒）/ 严格（×0.75）/ 关掉（只看对错，不按时间判模糊）
   ⑦ quizListen 出听音题：默认开；关掉后不出听音选义，学习新词第 2 关换成看义选词
   ⑧ quizSpell 出拼写题：默认开；关掉后不出拼写
   ⑨ roundSize「今天到期」每轮最多几个：15 / 25（默认）/ 40 / 不限（仍受每天复习上限 dailyCap 约束）
2. 设置页（renderSettings）：「背词」一节拆成「学习新词」（①②④）和「复习」（考试日期、每天复习上限、⑨、出题方式 drillMode、抽查顺序 drillOrder、③、⑤、⑥、⑦、⑧）；「讲解视频优先用」挪到「学习」一节（课文页也用）。巩固页上的出题方式、抽查顺序保留，和设置页是同一个值
3. 复习规则（site/srs.js，核心模块，改了同步改 tests/srs.test.js）：
   - gradeChoice 判模糊的时限乘一个倍数（opt 传入，默认 1；0 = 不按时间判模糊）
   - pickType、level 支持「关掉的题型」：出题时遇到关掉的题型，换成梯子上下一个没关的（听音关掉 → 看词选义答对过就直接升到例句题；拼写关掉 → 最高到例句题 / 看义选词）；算熟练度时关掉的题型不作要求（拼写关掉：5 级只要 s≥4 且连对≥4，同词组卡的规则；听音关掉不影响 4 级，4 级本来就看例句题）
   - 文件开头的规则说明、docs/plans/2026-10-01-vocab-portal.md 里的规则说明同步改
4. site/study.js 用上这些设置：ROUND → roundSize；学习新词的关数、取词、自动读；autoNext；把 slowMode、quizListen、quizSpell 传给 SRS
【不做】
- 看完词卡隔几张再考（3～5 张）、答错的隔几张再出（3～5 张）：不开放，细节，改了影响不大
- 复习间隔天数、考前封顶、一天从凌晨 4 点开始算：不开放，改错复习安排会悄悄乱
- 同时在背几个（WINDOW = 8）、「上一个」回看上限（30）
- B、C 两条不冒新设置：分屏是开关按钮，速览展开 / 收起自动记住
【已定的取舍】
- 默认值全部等于现在的行为：加了设置不改变原来的用法
- 一个「自动读单词」管学新词和复习两处：安静场合关一次就够
- 关掉题型时熟练度放宽而不是卡死：不然关掉拼写后永远到不了 5 级，复习间隔一直拉不开
【默认假设】
- 改了设置从下一题 / 下一轮开始生效，正在做的这一轮不重排（学习新词的 learnSize 从下一次进学习新词开始）
- learnSize 多群时，每一群的词全部过关就把那一群记为学过（不等整轮），中途退出时已完成的群照样算数
- C 的速览：一次学多群时，速览显示当前这个词所在的那一群，换到下一群的词时自动切过去
- autoNext 停顿 1.5 秒，不另开设置
- slowMode 的倍数作用在所有题型的时限上（词组卡按看词选义的时限）
- 翻卡自评模式不受 ⑤⑥⑦⑧ 影响
【验收】
- node --test "tests/*.test.js" 全过（新增：时限倍数、0 不判模糊；关掉听音 / 拼写后 pickType 跳过、level 能到 5 级；默认参数下原有测试全部不变）；python pipeline/validate.py 0 错误
- 本地 8775 走查（电脑和 375 宽各一遍）：设置页两节显示正确；全部默认时学习新词、今天到期和改之前一样（回归）；逐项改：1 关 / 3 关、2 群 / 至少 15 词、关自动读单词（学新词词卡不读）、开自动读例句、开答对自动下一题（1.5 秒后跳、答错不跳、按键能停）、宽松 / 关掉模糊、关听音（学新词第 2 关变看义选词，复习不出听音）、关拼写、每轮 15 / 不限
- 另一台设备（或另一个端口）刷新后设置同步过来
【线索】
- 设置：site/app.js 的 DEFAULTS、setS、renderSettings（seg、sw 两个小工具），点击 / change 处理在 $("#settingsView") 上
- 巩固：site/study.js 的 ROUND、WINDOW、renderPicker（drillMode、drillOrder 的现成切换）、kindFor（学习新词第几关出什么题）、settle（过关条件 s.stage >= 2）、answer（判分）、learnItems / learnTarget / finishLearn / progSave（进度字段 g）
- 复习规则：site/srs.js 的 SLOW_MS、gradeChoice、level、pickType、isPhrase；测试 tests/srs.test.js
```
