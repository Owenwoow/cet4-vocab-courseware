# 云同步使用说明

让电脑、手机等多台设备自动共享学习进度：「已会」记录、所有设置、上次读到哪一课哪个词、侧边栏收起状态。进度存在你自己 GitHub 账号里的一个私密 Gist（GitHub 自带的小文件存储），不需要服务器。

## 一、同步原则

**自动同步，平时什么都不用点。** 设置页的「立即同步」只是备用按钮，用来马上确认一次状态。

### 什么时候同步

| 时机 | 做什么 |
|---|---|
| 打开页面 | 拉取云端进度，和本机合并 |
| 切回页面（切换标签页、从别的 App 回到浏览器） | 拉取 + 合并，有本机改动就一并推上去 |
| 切走页面 | 立刻把本机还没推的改动推上去 |
| 标「已会」、改设置 | 停手约 3 秒后自动推送 |
| 滚动阅读（位置变了） | 约 20 秒推送一次，阅读位置变化太频繁，不用每次都推 |
| 断网后恢复联网 | 自动补推 |

两次写入云端至少间隔 10 秒，避开 GitHub 对写入频率的限制。

### 本地优先

- 所有操作先存在本机，**断网也照常使用**，联网后自动补上
- 云端连不上时，设置页会显示原因（网络不通、token 过期等），但不影响学习

### 两台设备都改了怎么办

- 每一项数据单独记一个"最后修改时间"：每个词的「已会」、每项设置、每课的阅读位置都是分开记的
- 合并时**逐项比较，留下改得更晚的那一份**，不会整份覆盖
- 例子：电脑上标了 A 词已会，手机上同时标了 B 词已会，同步后两台设备上 A、B 都是已会
- 取消「已会」也会被记录，所以在一台设备上取消，另一台也会跟着取消

### 换设备时自动接着读

- 拉取时如果发现别的设备读到了更新的位置，页面会**自动跳到那一课的那个词**，底部弹出「已接上其他设备的进度：Unit x · Lesson y」
- 在设置页时不会跳转，只刷新数据
- 本机刚打开、还没和云端同步完时，不会记录阅读位置，以免本机的旧位置盖掉别的设备更新的位置

### 存了什么、没存什么

- 会同步：「已会」记录、设置（声音、语速、背诵模式、隐藏已会、磨耳朵选项、主题）、上次打开的课、每课读到的词、侧边栏收起状态
- 不会同步：token 本身。它只存在每台设备自己的浏览器里，所以每台设备都要粘贴一次

## 二、开启步骤

### 第一步：在 GitHub 上建 token（只需一次）

token 是一串类似密码的字符，网页凭它读写你账号里的私密 Gist。

1. 电脑浏览器登录 GitHub，打开 https://github.com/settings/personal-access-tokens/new
   - 手动进入：右上角头像 → **Settings** → 左侧栏最底部 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
   - GitHub 可能要求再输一次密码或做两步验证
2. 按下表填写：

| 栏目 | 填什么 | 说明 |
|---|---|---|
| **Token name**（名字） | `cet4-课件同步` | 给自己看的标签，能认出用途就行；也可以用 `cet4-progress-sync` |
| **Description**（描述，可选） | `四级词汇课件多端同步进度，只有 Gist 权限` | 可不填 |
| **Resource owner**（归属） | 你自己的账号 `Owenwoow` | 默认就是 |
| **Expiration**（有效期） | 最长的一档：有 **No expiration** 选它，否则选 **Custom** 并拉到最远日期（一般一年） | 过期后重建即可，见第四节 |
| **Repository access**（仓库范围） | **Public repositories** | 同步不碰仓库，选权限最小的 |

3. **Permissions（权限）**，最关键的一步：
   - 在 **Account permissions** 里找到 **Gists**（新版界面可能要先点 **Add permissions** 再勾选）
   - 把它从 `No access` 改成 **Read and write**
   - **其他权限一律不动**，尤其是 Repository permissions
4. 拉到最底部点 **Generate token**。权限摘要里应该只有一条：Gists 读写
5. 复制页面上那串以 `github_pat_` 开头的字符
   - ⚠️ 只显示这一次，离开页面就看不到了
   - 存进密码管理器或私密备忘录，手机上还要用
   - 不要发给别人，不要贴进聊天或代码

### 第二步：电脑上连接

1. 打开 https://cet4.owenwoow.com/ （已经开着就刷新一下）
2. 点右上角 **⚙** → 拉到最底部 **「云同步」**
3. 粘贴 token（显示成圆点是正常的）→ 点 **「连接」**
4. 成功时底部弹出「云同步已开启」，面板显示「已开启 · 已同步 · 刚刚」

**确认云端已存上**：打开 https://gist.github.com/ （头像 → **Your gists**），应该能看到一个标着 **Secret** 的 Gist：

- 描述是「四级词汇课件 · 学习进度（自动同步，请勿手改）」
- 文件名是 `cet4-progress.json`

这个 Gist 是网页自动建的，**不用你取名，也不要改名或删除**，网页靠文件名找到它。

### 第三步：手机上连接

1. 手机浏览器打开 https://cet4.owenwoow.com/
2. ⚙ → 「云同步」→ 粘贴**同一个 token** → 「连接」
3. 连上后会自动拉取电脑上的进度，读过的课会直接跳过去

所有设备共用一个 token，不用再建第二个；每台设备、每个浏览器只需粘贴一次。

## 三、注意事项

- **必须在新网址下粘贴**：token 按网址分别保存。旧的 github.io 地址会自动跳到 `cet4.owenwoow.com`，在新网址下粘贴就行
- **换浏览器、清了浏览器数据**：重新粘贴一次 token 即可，进度在云端不会丢
- **不想让某台设备同步了**：在那台设备上点「断开」。只删除这台设备上保存的 token，云端和其他设备都不受影响
- **「已会」的清空按钮**：开启同步后，清空会同步到所有设备

## 四、出问题怎么办

| 设置页显示 | 原因 | 处理 |
|---|---|---|
| token 无效或已过期，请重新粘贴 | token 到期或被删 | 按第一步重建一个（名字可以加年份，如 `cet4-课件同步-2027`）；在每台设备上点「断开」后粘贴新的。云端进度不受影响 |
| token 没有 Gist 读写权限 | 建 token 时 Gists 没设成 Read and write | 到 https://github.com/settings/personal-access-tokens 点开这个 token，改好权限后保存，不用重新粘贴 |
| 网络不通，联网后自动重试 | 断网 | 不用管，联网后会自动补上 |
| GitHub 暂时不可用，稍后自动重试 | GitHub 故障或请求太频繁 | 不用管，稍后会自动重试 |

**怀疑 token 泄露**：到 https://github.com/settings/personal-access-tokens 找到 `cet4-课件同步`，点 **Delete** 删掉，再重建一个。这个 token 只能读写 Gist，碰不到你的代码仓库。

GitHub 页面偶尔会改版，按钮位置可能和上面略有出入，但栏目名称（Token name、Expiration、Gists 权限）基本不变。
